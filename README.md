## 00 / About

**Aldi Pradana Hakim** — informatics engineering student in Indonesia who ships full-stack web apps end to end: schema and migrations, API and auth, then the last screen people actually click.

The work I take on usually has a state machine behind it — signed payloads arriving from devices in the field, stock that has to stay correct after every sale, reports someone has to be able to download. So I write the whole vertical slice instead of handing it across three people.

- 🛰️ Currently finishing **AF GPS Tracker** — Laravel · MQTT · ESP32 firmware · Android
- 🧾 Shipped **POS Kasir Toko Sembako** — Express · PostgreSQL · React PWA, offline-first on IndexedDB
- 💬 Open to freelance work — usually replies within one business day
